EXECUTION FLOW
==============

membership::test_basic_join_leave:
    1. Create FlowBuilder
    2. Set up external source and process node
    3. Connect membership tracking
    4. Run exhaustive simulation
    5. Send join event
    6. Assert member appears in output

membership::test_multiple_members_join_leave:
    1. Create FlowBuilder
    2. Set up flow components
    3. Compile simulation once
    4. Scenario 1: Test multiple joins
    5. Scenario 2: Test member leaving
    6. Scenario 3: Test member rejoining

request_response::test_join_responses_basic:
    1. Create FlowBuilder
    2. Set up tick-based metadata source
    3. Set up response stream
    4. Connect join_responses function
    5. Run exhaustive simulation
    6. Send metadata then responses
    7. Assert joined pairs

request_response::test_join_responses_delayed_response:
    1. Create FlowBuilder
    2. Set up streams
    3. Run exhaustive simulation
    4. Send metadata for keys 1 and 2
    5. Send response only for key 1
    6. Assert only key 1 produces output

rolling_average::test_basic_statistics:
    1. Create RollingAverage instance
    2. Add 5 samples (10, 20, 30, 40, 50)
    3. Verify sample count (5)
    4. Verify mean (30.0)
    5. Verify variance (250.0)
    6. Verify std dev (15.811...)

rolling_average::test_edge_cases:
    1. Test empty instance
       - Verify count = 0, mean = 0.0
    2. Test single sample
       - Verify variance = 0, CI = None
    3. Test negative values
       - Verify correct processing

rolling_average::test_combine_averages:
    1. Create two separate instances
    2. Add samples to each
    3. Combine using add() method
    4. Verify aggregated count and mean

rolling_average::test_confidence_interval:
    1. Create instance with 10 samples
    2. Compute 99% confidence interval
    3. Verify interval exists
    4. Verify mean within interval
    5. Verify symmetry
